# Резервная копия ответов в Google Таблице

Таблица «LOONSISTERS — ответы маркетинговой анкеты» создана по адресу:
https://docs.google.com/spreadsheets/d/1vEroFeq3f1jvGdWf_IoSG1p7P3g_hbZoUJWluZMrec0/edit

Ответы остаются в SQLite на `/data` и попадают в таблицу после завершения анкеты. Один номер заказа соответствует одной строке; повторная отправка обновляет строку.

1. В аккаунте владельца таблицы откройте **Расширения → Apps Script**. Замените содержимое `Code.gs` кодом из `google_sheets_webhook.gs` и сохраните.
2. Откройте **Настройки проекта → Свойства скрипта**. Создайте `LOONS_SHEET_ID` со значением `1vEroFeq3f1jvGdWf_IoSG1p7P3g_hbZoUJWluZMrec0`. Создайте `LOONS_WEBHOOK_SECRET` со случайной строкой длиной не менее 32 символов. Не публикуйте её.
3. **Развернуть → Новое развертывание → Веб-приложение**: выполнять от своего имени; доступ «Все» (Anyone). Подтвердите доступ скрипта к таблице и скопируйте URL вида `https://script.google.com/macros/s/.../exec`.
4. В существующем проекте Amvera добавьте защищённые переменные `GOOGLE_SHEETS_WEBHOOK_URL` (URL из предыдущего шага) и `GOOGLE_SHEETS_WEBHOOK_SECRET` (тот же секрет). Перезапустите приложение. Старый `GETCOURSE_API_KEY` не менять.

Доступ «Все» относится только к точке приёма: она проверяет HMAC подпись по закрытому секрету, а сама таблица не становится общедоступной. При ошибке ответ остаётся в `/data`, повторная доставка происходит через 5 минут. Проверить можно одной согласованной тестовой анкетой и по строке `STRATEGY_BACKUP confirmed` без персональных данных в логе. Запись GetCourse проверяется отдельно.
